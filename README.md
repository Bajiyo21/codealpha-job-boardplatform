# CareerNest – Job Board Platform

CareerNest is a backend job portal built using Django REST Framework.

## Features

- JWT Authentication
- Employer & Candidate Roles
- Company Profile Management
- Job Posting CRUD APIs
- Resume Upload
- Job Applications
- Employer Dashboard
- Search & Filters
- Swagger Documentation

## Tech Stack

- Python
- Django REST Framework
- PostgreSQL
- SQLite (Development)
- JWT Authentication
- Swagger OpenAPI
